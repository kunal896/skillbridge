# Demo Flow

Target demo:

1. Learner enters a sample profile: Retail Associate → Data Analyst.
2. Diagnosis extracts current skills and gaps.
3. Roadmap agent retrieves relevant job postings.
4. UI shows a cited, sequenced roadmap.
5. Learner opens the first locked skill node.
6. System generates a coding micro-project.
7. Submission is sandboxed and graded.
8. Passing unlocks the next node.
9. Employer view shows the learner's verified skills.

The proposal's intended killer moment is a side-by-side comparison with generic LLM advice: SkillBridge should show sources and verification rather than generic uncited recommendations.
